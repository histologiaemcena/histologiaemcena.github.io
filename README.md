# Histologia em Cena

Acervo on-line de lâminas histológicas e histopatológicas do projeto de extensão **Histologia em Cena**
(Universidade Federal de Mato Grosso, Campus Universitário do Araguaia).

Site: https://histologiaemcena.github.io

Este repositório contém apenas o site pronto (gerado). Os arquivos de trabalho e os scripts que
geram o site ficam na pasta de desenvolvimento do projeto (`02_desenvolvimento`): para atualizar,
rode `extrair_catalogacao.py` e `construir_site.py` e envie aqui o conteúdo de `03_publicacao`.
